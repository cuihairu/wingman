# Config Switch Effects

This page shows the **off / on** visual states and the toggle animation for the
Runtime GUI settings switches. The screenshots and GIFs are generated by the
re-runnable pipeline at `apps/gui/scripts/capture-config-gifs.mjs`; run it
whenever the settings layout or switch semantics change, and commit the diff as
a visual regression check.

## Prerequisites

- GUI dev server running: `cd apps/gui && pnpm dev` (default `http://localhost:5173`)
- `playwright-core` installed (`pnpm add -D playwright-core`), a local Chromium under
  `~/.cache/ms-playwright`, and `magick` or `ffmpeg` for GIF synthesis

## Re-run

```bash
cd apps/gui
node scripts/capture-config-gifs.mjs
```

## Switches

### Auto Reconnect

When the GUI loses its IPC connection to the Runtime, it automatically retries.

![auto-reconnect off](/config-effects/auto-reconnect-off.png)
![auto-reconnect on](/config-effects/auto-reconnect-on.png)
![auto-reconnect toggle](/config-effects/auto-reconnect.gif)

### Auto Start

When the GUI starts, it automatically loads and starts the active profile's scripts.

![auto-start off](/config-effects/auto-start-off.png)
![auto-start on](/config-effects/auto-start-on.png)
![auto-start toggle](/config-effects/auto-start.gif)

### Minimize to Tray

When the GUI starts, it minimizes to the system tray.

![minimize-to-tray off](/config-effects/minimize-to-tray-off.png)
![minimize-to-tray on](/config-effects/minimize-to-tray-on.png)
![minimize-to-tray toggle](/config-effects/minimize-to-tray.gif)

### Challenge Auth

When enabled, remote registration uses the HMAC challenge-response flow instead
of sending the registration token in plaintext.

![challenge-auth off](/config-effects/challenge-auth-off.png)
![challenge-auth on](/config-effects/challenge-auth-on.png)
![challenge-auth toggle](/config-effects/challenge-auth.gif)
