# 视频教程系列分镜脚本

ROADMAP M8.2「视频教程」的前期交付物：可直接照录的系列分镜脚本（画面动作 +
旁白文本）。实拍录制需在真实 Windows 环境操作 GUI，由人工完成；本文保证
录制者不需要再理解产品即可开机录。

## 系列约定

- 受众：第一次接触 Wingman 的使用者（不假设会 Go/C++ 开发）。
- 每集 ≤ 8 分钟，一集只讲一条主线；操作失误直接剪掉，不回滚重演。
- 旁白用简短陈述句，无营销话术；术语与 docs/guide 一致（Runtime / GUI /
  中控 / Agent / 触发器 / 宏）。
- 录制规格：1920×1080、60fps；鼠标移动放慢，点击处停留 ≥1s；全程 100% 缩放。
- 片头统一：logo 3s + 本集标题；片尾统一：下一集预告 5s + 文档链接字幕。
- 文件命名：`ep01-install-first-run.mp4`（小写连字符），字幕随视频同发 SRT。

## EP01 安装与首次启动

前置：干净 Windows 10/11 虚拟机，已下载 Release 产物（安装包 + 便携 ZIP 各一份）。

| # | 画面 | 操作 | 旁白要点 |
|---|------|------|----------|
| 1 | 桌面 | 打开 Releases 页 | 「Wingman 提供两种发行形态：安装包和便携版。」 |
| 2 | 下载目录 | 双击 InnoSetup 安装包，默认下一步走完 | 「安装包安装到 Program Files；便携版解压即用。」 |
| 3 | 开始菜单 | 启动 Runtime | 「Runtime 是本机执行器，首次启动会生成默认 agent.toml。」 |
| 4 | Runtime 日志 | 指出 outbound 连接尝试日志 | 「Runtime 只主动向外连接中控，本机不开控制端口。」 |
| 5 | 命令行 | `wingman-agent.exe run examples/hello.lua` | 「命令行可以直接跑 Lua 脚本，不需要中控。」 |
| 6 | 输出窗口 | 展示 hello 输出 | 「屏幕尺寸与延迟函数来自内置 util 模块。」 |
| 7 | 便携 ZIP | 解压到 D 盘，运行同脚本 | 「便携版与安装版行为一致，适合 U 盘携带。」 |
