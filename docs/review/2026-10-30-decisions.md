## 条目 1：视频教程 EP01 机器侧素材预采

**位置**：`todo.md:8`；`ROADMAP.md:569-580`（M8.2 视频教程）。

**当前状态**：环境级 BLOCKED。

**事实**：EP01 需要的可交付物已全部就绪——`wingman-agent.exe` 已就位 win-worker `D:\wingman-tutorial\agent-bin\`（nightly 184c7de zip，sha256 与官方 digest 一致，`ROADMAP.md:574-575`）；零注入录屏管线（进程创建预载 PowerShell + ffmpeg gdigrab 60fps + ffprobe）已逐步全 PASS（`ROADMAP.md:575-576`）；六集分镜、逐字旁白、录制规格均已在 `docs/tutorials/video-storyboard.md` 完备，发布检查单在其行 105、EP01 机器侧预采配方在 `docs/zh/tutorials/video-storyboard.md:46`（`ROADMAP.md:570-572` 引用英文 `docs/tutorials/video-storyboard.md`，该英文文件不含机器侧预采配方，配方仅在中文文件）。唯一卡点：win-worker 已按用户 2026-10-27 令**永久停用**（`ROADMAP.md:577`），而 EP01 预采依赖其**桌面解锁**。

### 推荐决策

**暂缓，需用户输入。** 等待用户二选一：① 提供已解锁的 Windows 真机；② 明确授权人工执行机器侧预采（照配方约 2 分钟出片）。在此之前不虚构进展、不生成代餐素材（维持 `ROADMAP.md:580` 既有红线）。

### 理由（面向非专业用户）

- **收益**：预采是 EP01 成片的唯一前置。素材到手后，后续人工成片即可从「录」开始，无需再准备环境。
- **成本**：仓库侧零剩余工程——脚本包、预采配方、录屏管线、agent exe、sha256 校验全部就绪（`ROADMAP.md:572-576`），用户只需出一台解锁机器或一句话授权，成本在用户侧而非仓库侧。
- **风险 1（卡点本质）**：预采涉及目标机器的**桌面会话与凭据**（在已解锁桌面里运行 agent、录屏），不是纯仓库内可逆改动。按授权口径，涉凭据/桌面会话的事项**不代决、不硬做**。
- **风险 2（教学性说明）**：为什么「桌面解锁」如此关键？录屏捕获的是当前可见桌面；如果机器空闲自动锁屏，抓到的会是锁屏界面（LockApp/LogonUI，`ROADMAP.md:578` 双证 LOCKED），而不是教程需要的 Wingman 窗口画面。所以必须有一台**保持解锁**的机器才能录，这正是 win-worker 停用后卡住的原因。
- **风险 3**：若绕过用户授权自行找机器预采，既违反「涉凭据/桌面会话不代决」红线，也会让成品素材来源存疑（无用户认可的环境 = 素材可信度低，成片后仍要返工）。

### 立即执行动作

无。仓库侧无低风险可逆动作可做；唯一动作（预采）涉桌面会话/凭据，需用户输入。

**待用户**：① 提供已解锁的 Windows 真机；或 ② 明确授权人工执行机器侧预采（照 `docs/zh/tutorials/video-storyboard.md:46` 配方约 2 分钟出片）。

### 明确不做 / 延后什么

- 不自行找机器预采、不生成代餐/占位素材（维护 `ROADMAP.md:580` 红线：不虚构进展）。
- 不把「win-worker 停用」当作可绕过项处理（它来自用户 2026-10-27 令，是硬约束，只能等用户改口或提供替代机器）。
- 不勾除本条目（`todo.md:8` 保持未完成），直到素材真实产出。
